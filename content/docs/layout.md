# Layout

The screen is three quiet regions. The reading column stays wide enough for a line of thought, and the chrome around it stays still.

## Files

The left column lists every page. The open page is marked. Search sits over the screen, so the list can remain a list.

## Page

Preview is the default, because this is a place to read. Split puts the source beside the preview when you are changing a page. Source is the file alone.

## Outline

Headings on the open page are listed on the right. The heading nearest the top of the viewport is marked. Choose one to scroll there.
