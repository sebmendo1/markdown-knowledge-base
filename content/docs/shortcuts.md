# Shortcuts

The keyboard covers the actions you repeat. Commands with ⌘ also work while you type. Single keys work while you read.

## Keyboard

| Keys | Action |
| --- | --- |
| `⌘K` | Search pages |
| `E` | Edit the page as blocks |
| `⌘/` | Switch between blocks and Markdown source |
| `C` | Create a page in this folder |
| `⌘S` | Save a version |
| `⌘\` | Show or hide the outline |
| `⌘,` | Open settings |
| `?` | Show this list |

## While editing

| Keys | Action |
| --- | --- |
| `/` | Insert a block: heading, list, to-do, callout, code, math, diagram, chart, table, embed |
| `[[` | Link to a page |
| `#`, `-`, `1.`, `[ ]`, `>` then space | Turn the line into a heading, list, to-do, or quote |
| `⌘B`, `⌘I`, `⌘E` | Bold, italic, inline code |
| `Esc` | Close a block's source and return to the page |

On Linux and Windows, Ctrl is the modifier.
