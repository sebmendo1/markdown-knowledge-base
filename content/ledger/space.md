# About this space

markdown-kb keeps notes as Markdown files. This screen is for reading and editing them: prose, tables, math, diagrams, and charts.

The files in `content/` are the knowledge base. A change in the editor is a draft in this browser. Reset returns the page to the file in the repository.

Sign-in, agents, and review come later. The reading column is the part that has to feel right first.
